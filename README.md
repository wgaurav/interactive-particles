# Palm Promax Gold — Interactive Landing Page

**[▶ View Live](https://wgaurav.github.io/interactive-particles/)**

Full scroll-driven landing page for Palm Promax Gold ($PPG), built with Three.js and custom GLSL shaders.

---

## Experience

1. **Bar assembles** on load — 3D gold bar forms from particles with the Palm Promax logo
2. **Scroll** to reveal the tagline *"Physical Gold, Digital Access."*
3. **Continue scrolling** — camera zooms in, logo disintegrates, bar dissolves into floating particles
4. **Waitlist form** fades in — fill out to join the founders list
5. **Success state** — confirmation with partner logo rings

## Interaction

- **Hover / drag** over the bar to interact with particles
- **Scroll** drives the full animation sequence
- Works on desktop and mobile
